## 💻 Sobre o projeto

O **Tech News** é uma página web de um portal de notícias focado em tecnologia (Inteligência Artificial, Blockchain, Hologramas, Realidade Virtual, entre outros).

Este projeto foi desenvolvido com foco no domínio de layouts complexos utilizando **CSS Grid Layout**, variáveis CSS, classes utilitárias e boas práticas de semântica no **HTML5**.

## 🚀 Tecnologias utilizadas

O projeto foi construído utilizando as seguintes tecnologias e conceitos:

- **HTML5 Semântico** (`header`, `nav`, `main`, `section`, `article`, `aside`, `figure`)
- **CSS3 Moderno**
  - **CSS Grid Layout** (`grid-template-areas`, `grid-template-columns`, `grid-auto-flow`)
  - **CSS Nesting** (aninhamento nativo de seletores)
  - **Custom Properties** (Variáveis CSS)
  - **Utility-First CSS** (classes utilitárias para espaçamento, tipografia e grid)
- **Google Fonts** (Fonte _Archivo_)
